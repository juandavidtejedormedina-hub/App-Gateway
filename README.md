# App Gateway

Aplicación de Elite Flower con el asistente original y una nueva sección visual
de Gateways. La navegación superior permite cambiar entre ambas vistas. El
ajedrez se retiró.

La sección Gateways es la primera interfaz del proyecto: sus indicadores están
marcados como pendientes hasta conectar una fuente de datos. No incluye
coordenadas ni archivos geográficos de la empresa en el repositorio público.

Compatible con Streamlit Community Cloud.

## Ejecución local

```bash
pip install -r requirements.txt
streamlit run app.py
```
